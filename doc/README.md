# AT&T QA PoC - Documentación

## Estructura de carpetas

- **01_RPA/** - Scripts, evidencias y documentación de automatizaciones RPA (flujos Salesforce)

- **03_Performance_Testing/** - Scripts de carga (2k VUs / 3600s), resultados y reportes
- **04_Framework/** - Orquestación, gobierno, estándares e integración con IA
- **05_Documentacion/** - Arquitectura, tech stack y material de presentación
- **06_Evidencias/** - Evidencias generales y capturas de ejecuciones
